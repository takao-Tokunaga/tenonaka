# 香りのしおり(仮) 要件定義書

## テーマ

ハッカソンテーマ:「AIにできないこと」

## コンセプト

本を開くと、今日のページが現れる。日記と匂いの記録(しおり)を書き込める。
過去はスワイプでページを遡って読み返せる、個人の記録アプリ。

匂いの言語化・記憶の想起は、AIには原理的に体験できない領域である。
そのため本アプリはAIを一切使用せず、解釈・要約・レコメンドを挟まずに
ユーザー自身の言葉だけで完結する設計を採る。

## 体験の核

- 匂いを感じた瞬間の記憶を、その日の日記の中に「しおり」として挟み込む
- 過去のページをスワイプでたどっている中で、しおりが挟まっているページに
  偶然出会う体験を大事にする(一覧性をあえて持たせない)
- しおりの存在は事前にわからず、ページを開いた後にアイコンがフェードイン
  して初めて気づく「発見」の演出とする

## 画面構成

1. **起動画面**
   本を開くアニメーション → その日の日付ページへ遷移

2. **日付ページ(メイン画面)**
   - 日記入力欄(自由記述)
   - しおりを挟むボタン(ページ隅) → しおり記録モーダル
     (匂いのタグ・匂いの言葉・記憶の言葉)
   - 何も記録がなくても、その日の日付だけ書かれた空白ページとして表示される

3. **過去ページ閲覧**
   - スワイプで前後の日付ページへ移動(ページめくりアニメーション)
   - 未記入の過去ページは白紙のまま表示(特別な表示は入れない)
   - しおりがあるページは、ページを開いた後(約0.3秒後)にアイコンが
     フェードインする
   - アイコンをタップすると、匂いの言葉・記憶の言葉が展開される

## 機能要件(MVP)

| # | 機能 | 内容 |
|---|------|------|
| 1 | 日付ページの表示 | 1日1ページ、日記+しおりを保持 |
| 2 | 日記の記入 | 自由記述テキスト |
| 3 | しおりの記入 | タグ選択(固定+自由入力)・匂いの言葉・記憶の言葉。1日1件まで |
| 4 | ページ遷移 | スワイプによる過去/未来ページへの移動 |
| 5 | しおりの発見演出 | ページ表示後、しおりアイコンをフェードイン表示 |
| 6 | しおりの展開 | アイコンタップで匂い・記憶の詳細を表示 |

### スコープ外(MVPでは実装しない)
- プッシュ通知・リマインド
- 検索・フィルタリング
- 音声入力
- 複数ユーザー・共有機能
- 地図表示(将来的な拡張候補として保留)

## データ設計

### Prismaスキーマ

```prisma
model DiaryPage {
  id            String   @id @default(uuid())
  date          DateTime @unique
  diaryText     String?
  tag           ScentTag?
  customTagText String?
  scentText     String?
  memoryText    String?
  userId        String
}

enum ScentTag {
  SWEET       // 甘い
  NOSTALGIC   // 懐かしい
  EARTHY      // 土っぽい
  CLEAN       // 清潔
  BITTER       // 苦い
  SMOKY       // 煙っぽい
  FLORAL      // 花のような
  CUSTOM      // その他(自由入力)
}
```

日記としおりはそれぞれ任意項目とし、「日記だけ書く日」「しおりだけ挟む日」
「両方書く日」いずれも成立するようにする。

## API設計(最小構成)

| メソッド | パス | 内容 |
|---|---|---|
| GET | /pages/:date | 指定日のページ取得 |
| PUT | /pages/:date | 指定日のページ更新(日記+しおり) |
| GET | /pages?before=:date&limit=:n | 過去ページを遡って取得(スワイプ用) |
| GET | /pages?from=:date&to=:date | 日付範囲のページ一括取得(ページャの先読み用) |

## 技術構成

- **iOS**:Swift / SwiftUI
  - ページめくりは独自のドラッグジェスチャー + 3D回転アニメーションで実装
  - しおりのフェードイン演出はページ表示後の遅延アニメーションで実装
  - オフライン時もローカルキャッシュで閲覧・記入できるようにする
- **バックエンド**:NestJS + Prisma + PostgreSQL(Docker)
- **認証**:ハッカソン規模のため簡易実装(`x-user-id` ヘッダによる固定ユーザーID)

## 確定した論点

- しおりを新規に挟む際のUI → **日記入力欄とは別のボタンを置き、モーダル
  (シート)で入力する**。「しおりを挟む」という儀式感を出し、日記と匂いが
  別レイヤーであることを体験的に伝える
- 作法・世界観の細部 → **紙・本の質感を重視**。生成りの紙色、明朝系の
  セリフ体、罫線、ページめくりアニメーション

## 検討過程で不採用とした案(参考記録)

- 匂いをAIが解釈・要約する仕組み → テーマ趣旨(AIにできないこと)に反するため不採用
- 音声入力での記録 → 公共の場での利用ハードルが高いため不採用。
  タグ+テキストの2段階方式を検討したが、最終的には日記ページへの
  テキスト記入に統一
- 匂いをみんなで書き込む形式 → 個人の記憶・感情の深みを考え、
  実装コストも増すため一旦保留(将来的な拡張候補)
